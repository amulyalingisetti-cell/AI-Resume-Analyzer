# AI Resume Analyzer & Job Recommendation System

## Objective
NLP-based app to match resume with job roles and provide learning roadmap.

## Features
- Upload PDF/DOCX resumes
- Extract and clean text
- Skill extraction from 120+ skills
- Cosine similarity job matching
- Skill gap analysis + Learning Roadmap
- Downloadable report

## Tech Stack
Python, Streamlit, scikit-learn, pandas, pdfplumber

## How to Run
1. pip install -r requirements.txt
2. streamlit run app.py
